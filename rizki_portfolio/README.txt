# Rizki Nugraha Samar Dwi Saputra — Portfolio

## Struktur
- index.html — Halaman pembuka / Open Access
- beranda.html — Beranda / Site Access
- tentang.html — Personnel Profile
- pengalaman.html — Field Experience
- pendidikan.html — Education Record
- keahlian.html — Skill & Capability
- kontak.html — Contact / Access Point
- style.css — shared stylesheet
- script.js — navigation, animasi, dan pemutar musik
- assets/profile.png — tempat foto profil
- Naruto Shippuden OST - Departure To The Front Lines.mp3 — soundtrack

## Cara menjalankan
1. Extract folder.
2. Jalankan folder melalui server web lokal, misalnya ekstensi Live Server di VS Code.
3. Buka `index.html` melalui alamat HTTP server, lalu pilih MASUK KE WEBSITE.
4. Musik mulai dari 01:06 saat tombol MASUK KE WEBSITE diklik dan berlanjut saat beranda terbuka; tidak perlu menekan tombol Play terpisah.
5. Browser dapat memblokir audio jika halaman dibuka langsung lewat `file://`; gunakan alamat HTTP dari server lokal.
6. Untuk memakai foto profil, masukkan foto ke `assets/profile.png`.
7. Semua halaman memakai `style.css` yang sama.

Catatan:
- Data periode WOM Finance sengaja ditulis "PERIOD TO BE CONFIRMED" karena tanggal belum dikonfirmasi.
- Foto belum ditanam otomatis agar struktur website tetap mudah diedit.
